# concert7.github.io

Website of [Concert7](https://github.com/pschopen/concert7), a free true stereo reverb plugin for classical music,
made for the free Bricasti M7 impulse responses recorded by Samplicity.

Live at <https://concert7.github.io/> – the documentation of all controls is at <https://concert7.github.io/docs/>.

Plain static HTML, no build step: `index.html` (onepager), `docs/index.html` (controls), `style.css` (shared styles).
GitHub Pages serves the `main` branch as is, so every push goes live within a minute.

Concert7 is an independent project and is not affiliated with Bricasti or Samplicity. Bricasti and M7 are trademarks
of their respective owner.
